# GUPet — пиксельный питомец для Windows

GUPet — интерактивный пиксельный питомец для рабочего стола Windows. Он живёт поверх окон, гуляет по экрану, прыгает, отдыхает, реагирует на курсор мыши, танцует под музыку и оставляет забавные реплики.

## Возможности

- **3 встроенных вида:** классический GUPet, кошка и собака; 6 цветовых палитр и настраиваемый масштаб (3.0x – 5.0x).
- **Пользовательские скины:** поддержка архивов `.gupet` с кадрами 18 × 13 пикселей. Установка, выбор и удаление прямо в настройках.
- **Интерактивность:**
  - *Клик* — питомец подпрыгивает и удивляется.
  - *Двойной клик* — высокий радостный прыжок с искрами.
  - *Частые клики* — забавное ворчание («Хватит тыкать!»).
  - *Поглаживание* — водите курсором мыши по питомцу, чтобы он замурчал и выпустил сердечки.
  - *Перетаскивание и бросок* — возьмите питомца и запустите его по экрану с реалистичной физикой и отскоками.
  - *Подвешивание к потолку* — забросьте питомца к верхней кромке экрана, и он зацепится лапками.
  - *Прятки* — питомец прячется за край экрана и выглядывает.
- **Танец под музыку:** автоматически определяет воспроизведение звука в системе (плеер, браузер, Spotify) и пускается в пляс с нотками.
- **Кучки:** питомец оставляет маленькие пиксельные кучки, которые можно убрать щелчком мыши (с подсчётом статистики).
- **Реплики:** десятки разнообразных фраз и реакций на любые события.
- **Поддержка системного трея:** контекстное меню в области уведомлений Windows и удобное окно настроек.
- **Полная автономность:** не требует установки дополнительных библиотек, .NET Framework или Java. Работает как единый компактный `.exe`.

## Управление

| Действие | Реакция |
| :--- | :--- |
| **Клик левой кнопкой** | Маленький прыжок, реакция |
| **Двойной клик** | Высокий прыжок с искрами |
| **Удержание и движение** | Перетаскивание / запуск с ускорением |
| **Поглаживание курсором** | Появление сердечек, мурчание |
| **Клик по кучке** | Уборка кучки со звуком и искрами |
| **Правый клик по питомцу** | Контекстное меню (вернуть в центр, кучки, вид, настройки, выход) |
| **Клик по значку в трее** | Открытие панели настроек |

## Пользовательские скины

Скин представляет собой архив с расширением `.gupet` (или `.zip`), содержащий `manifest.json` и PNG-кадры размером **18 × 13 пикселей**.

Обязателен файл `idle.png`. Дополнительные кадры: `blink.png`, `happy.png`, `sleep.png`, `dance.png`, `surprised.png`, `dizzy.png`, `angry.png`, `love.png`.

Пример структуры `manifest.json`:
```json
{
  "format": "GUPet",
  "formatVersion": 1,
  "id": "my-cool-skin",
  "name": "Мой скин",
  "author": "frizovdanya",
  "width": 18,
  "height": 13,
  "frames": {
    "idle": "idle.png",
    "blink": "blink.png",
    "happy": "happy.png",
    "sleep": "sleep.png",
    "dance": "dance.png",
    "surprised": "surprised.png",
    "love": "love.png"
  }
}
```

Готовый образец скина «Искра» включён в комплект поставки в папке `skins/`.

## Сборка из исходников

### Требования
- Компилятор MinGW-w64 (`x86_64-w64-mingw32-g++` для 64-бит и `i686-w64-mingw32-g++` для 32-бит)
- Утилита `make` (или CMake 3.16+)

### Сборка через Makefile:
```bash
# Сборка 64-битной и 32-битной версий
make -j4

# Или по отдельности:
make x64
make x86
```

Готовые исполняемые файлы будут собраны в папке `bin/`:
- `bin/GUPet_x64.exe` — Windows 64-bit
- `bin/GUPet_x86.exe` — Windows 32-bit
