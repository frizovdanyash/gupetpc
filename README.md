# GUPet — пиксельный питомец для рабочего стола (Windows и Linux)

GUPet — интерактивный пиксельный питомец для рабочего стола Windows и Linux. Он живёт поверх окон, гуляет по экрану, прыгает, отдыхает, реагирует на курсор мыши, танцует под музыку и оставляет забавные реплики.

## Возможности

- **Красивый интерфейс:** современное нативное окно настроек на Windows и Linux (GTK3) с карточками параметров, круглыми палитрами, интерактивными переключателями и живым анимированным предпросмотром питомца на карточке героя.
- **Любой размер питомца:** масштабирование без ограничений (от крошечного 1.0x до огромного 15.0x и свободный ввод любого коэффициента).
- **3 встроенных вида:** классический GUPet, кошка и собака; 6 цветовых палитр (Классический, Мятный, Лавандовый, Небесный, Розовый, Графит).
- **Пользовательские скины:** поддержка архивов `.gupet` с кадрами 18 × 13 пикселей. Установка, предпросмотр и удаление прямо в панели настроек.
- **Интерактивность:**
  - *Клик* — питомец подпрыгивает и удивляется.
  - *Двойной клик* — высокий радостный прыжок с искрами.
  - *Частые клики* — забавное ворчание («Хватит тыкать!»).
  - *Поглаживание* — водите курсором мыши по питомцу, чтобы он замурчал и выпустил сердечки.
  - *Перетаскивание и бросок* — возьмите питомца и запустите его по экрану с реалистичной физикой и отскоками.
  - *Подвешивание к потолку* — забросьте питомца к верхней кромке экрана, и он зацепится лапками.
  - *Прятки* — питомец прячется за край экрана и выглядывает.
- **Режим призрака (клик насквозь):** питомец не перехватывает клики мыши, позволяя комфортно играть и работать.
- **Танец под музыку:** автоматически определяет воспроизведение звука в системе и пускается в пляс с нотками.
- **Кучки:** питомец оставляет маленькие пиксельные кучки, которые можно убрать щелчком мыши (с подсчётом статистики).
- **Реплики:** десятки разнообразных фраз и реакций на любые события с диалоговыми облачками.
- **Автозапуск:** опция запуска вместе с операционной системой (Windows и Linux).
- **Системный трей:** удобное меню в трее / панели задач с быстрыми действиями.

## Управление

| Действие | Реакция |
| :--- | :--- |
| **Клик левой кнопкой** | Маленький прыжок, реакция |
| **Двойной клик** | Высокий прыжок с искрами |
| **Удержание и движение** | Перетаскивание / запуск с ускорением |
| **Поглаживание курсором** | Появление сердечек, мурчание |
| **Клик по кучке** | Уборка кучки со звуком и искрами |
| **Правый клик по питомцу** | Контекстное меню (вернуть в центр, кучки, вид, настройки, выход) |
| **Клик по значку в трее** | Открытие панели настроек Material 3 |

## Установка и запуск

### Windows
1. Скачайте архив `GUPet-v2.1.2-win64.zip` (или `win32` для 32-битных систем).
2. Распакуйте папку и запустите `GUPet.exe`.
3. Питомец появится в правом нижнем углу экрана, а в области уведомлений появится значок.
4. Для открытия настроек нажмите на значок в трее или щёлкните правой кнопкой мыши по питомцу и выберите **«Настройки...»**.

### Linux
1. Скачайте архив `GUPet-v2.1.2-linux-x64.tar.gz`.
2. Распакуйте архив:
   ```bash
   tar -xzf GUPet-v2.1.2-linux-x64.tar.gz
   cd GUPet-linux-x64
   ```
3. Для быстрой установки запустите скрипт:
   ```bash
   ./install.sh
   ```
   *Скрипт установит бинарник `gupet`, добавит ярлык в меню приложений и настроит иконку.*
4. Запустите питомца командой:
   ```bash
   gupet
   ```

## Сборка из исходников

### Требования
- **Linux:** `g++`, `make`, `libgtk-3-dev`, `libcairo2-dev`, `libpango1.0-dev`.
- **Windows (кросс-компиляция из Linux или MSYS2):** MinGW-w64 (`x86_64-w64-mingw32-g++` и `i686-w64-mingw32-g++`).

### Сборка через Makefile:
```bash
# Собрать все версии (Linux, Windows x64, Windows x86)
make all

# Или по отдельности:
make linux   # Сборка bin/gupet
make x64     # Сборка bin/GUPet_x64.exe
make x86     # Сборка bin/GUPet_x86.exe
```

## Пользовательские скины

Скин представляет собой архив с расширением `.gupet` (или `.zip`), содержащий `manifest.json` и PNG-кадры размером **18 × 13 пикселей**.

Обязателен файл `idle.png`. Дополнительные кадры: `blink.png`, `happy.png`, `sleep.png`, `dance.png`, `surprised.png`, `dizzy.png`, `angry.png`, `love.png`.

Пример `manifest.json`:
```json
{
  "format": "GUPet",
  "formatVersion": 1,
  "id": "iskra",
  "name": "Искра",
  "author": "frizovdanyash",
  "width": 18,
  "height": 13,
  "frames": {
    "idle": "idle.png",
    "blink": "blink.png",
    "happy": "happy.png",
    "sleep": "sleep.png",
    "dance": "dance.png",
    "surprised": "surprised.png",
    "love": "love.png"
  }
}
```

Скин можно загрузить прямо через интерфейс настроек кнопкой **«+ Импорт .gupet»**.
